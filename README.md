# BI Model for Monetizing Athlete Digital Audiences

Master's Thesis (Master's Degree in Business Data Analytics, UDIMA) proposing an analytical intervention model to transform football players' digital footprint into a monetizable asset, applied as a case study to two players from Club Gimnàstic de Tarragona, S.A.D.

## The Problem
In semi-professional categories such as Spain's 1ª RFEF, a player's commercial value is still measured almost exclusively by sporting performance, overlooking the economic value hidden in their digital footprint (social media reach, engagement, audience segmentation).

## The Solution
A BI model built in Power BI that cross-references sporting data (BeSoccer Pro) with Instagram and TikTok metrics to calculate each player's Earned Media Value (EMV) and estimated ROI as an advertising asset — enabling agencies to identify undervalued profiles and design data-driven "Match Branding" strategies with sponsors.

## Tools & Skills
- Power BI (data modeling, DAX measures, dashboard design)
- Excel / Power Query (ETL, data cleaning)
- Statistical analysis (correlation, dispersion, trend analysis)
